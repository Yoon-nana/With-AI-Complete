# 마빗 한 대에서 모드별 자동 전환

`checking.hex`와 `exercise.hex`에 학습 모델과 PC 연동 코드를 함께 넣었습니다. CreateAI에서 학습한 뒤 MakeCode에서 컴파일한 파일이며, 내장된 모델·클래스·실행 코드와 HEX 체크섬을 확인했습니다. 별도로 학습하거나 코드를 붙여 넣을 필요 없이 아래 연결 설정부터 진행하면 됩니다.

두 JSON은 원본 **학습 샘플**로 함께 보관합니다. manifest.json에는 샘플과 실행 HEX의 SHA-256, 클래스별 샘플 수를 기록했습니다.

| 모드 | 샘플 파일 | 클래스 | 앱이 사용할 실행 파일 |
|---|---|---|---|
| 기본 안부 감시 | Checking grandmother-data-samples.json | working / not working | checking.hex |
| 체조 | 체조-data-samples.json | rest / cheering / elbow curl / wrist circle | exercise.hex |
| 낮잠 | 위험 판단 중지 | 입력 결과를 사용하지 않음 | 현재 펌웨어를 유지하고 MODE,NAP 전달 |

## 모델을 다시 학습할 때

1. 각 데이터가 들어 있는 CreateAI 프로젝트에서 모델을 학습하고 실제 동작으로 테스트합니다.
2. 안부 감시 프로젝트의 MakeCode JavaScript에는 `microbit/checking_runtime.ts`를 넣습니다. working/not working 이벤트가 있는 해당 프로젝트에서 사용해야 합니다.
3. 체조 프로젝트의 MakeCode JavaScript에는 `microbit/exercise_runtime.ts`를 넣습니다. Rest/Cheering/ElbowCurl/WristCircle 이벤트가 있는 해당 프로젝트에서 사용합니다.
4. 각 프로젝트를 **학습 모델과 코드가 포함된 HEX**로 저장합니다. 일반 코드만 새 프로젝트에 붙이면 학습 모델이 포함되지 않습니다.
5. 이 폴더에 각각 `checking.hex`, `exercise.hex`로 저장합니다. JSON 이름이나 확장자를 바꾼 파일은 사용할 수 없습니다.

제공받은 원래 코드는 `checking_original.ts`, `exercise_original.ts`에 보존했습니다. runtime 파일은 원본 본문 뒤에 송수신·모드 안내·낮잠 스피커 제어만 추가했습니다. 배포본에 포함된 두 HEX의 실행 코드는 해당 runtime 파일과 일치합니다. 파일이 삭제되면 앱에 필요한 파일명을 표시하고, 전환에 성공했다고 표시하지 않습니다.

## 실제 자동 전환

- 마빗 V2를 USB 데이터 케이블로 PC에 연결하고 MICROBIT 드라이브가 보이게 합니다.
- 로보독 동글은 COM4, 마빗 USB는 별도의 COM 포트를 사용합니다.
- 낮잠 화면의 마빗 자동 전환 설정에서 마빗 COM을 지정합니다. MICROBIT 드라이브를 한 개 찾으면 자동 선택하며, 여러 개이거나 찾지 못하면 정확한 경로를 지정합니다. Windows 예: `D:/`.
- 체조로 바꾸면 USB 연결을 닫고 exercise.hex를 MICROBIT 드라이브에 복사합니다. 마빗이 다시 켜지고 EXERCISE 응답이 올 때까지 카운트를 기다립니다.
- 체조를 마치면 checking.hex를 같은 방식으로 복사해 기본 감시로 돌아갑니다. 펌웨어 전환에는 재시작과 연결 대기가 있습니다. 다운로드 중 USB를 분리하지 마세요.
- 낮잠은 모델을 바꾸지 않고 PC의 위험 판단을 쉬며, MODE,NAP 명령으로 마빗 내장 스피커를 끕니다. 낮잠을 마치고 기본 감시로 돌아오면 새 무활동 구간을 기다립니다. 외부 스피커 출력까지 차단하는 구현은 아닙니다.

## 횟수와 한계

- 체조 코드는 제공된 onStart 이벤트와 900ms 쿨다운을 그대로 사용합니다. 같은 클래스가 계속 유지되는 동안 자동으로 매번 횟수를 올리는 방식이 아닙니다. 동작 시작 이벤트가 다시 발생해야 합니다.
- 제공된 A/B 버튼의 수동 카운트 기능도 유지됩니다. PC는 마빗에서 올라간 카운트를 받으므로 A로 올린 횟수도 반영됩니다.
- PC는 누적 횟수의 증가분을 사용하며, 이전 횟수·중복 패킷·재시작·다른 운동을 미션 완료로 잘못 세지 않도록 처리합니다.
- 실기기 연결·실제 모델 정확도·실제 펌웨어 자동 다운로드는 아직 검증하지 못했습니다. 모의 통신과 임시 MICROBIT 드라이브로 코드를 검증합니다.
